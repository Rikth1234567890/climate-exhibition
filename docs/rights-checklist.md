# Rights Checklist

Every media file used in the final presentation must have an entry here.

**Rights status codes:**
- `NASA_CREDIT_REQUIRED` — NASA media; credit line must be shown with the item.
- `NOBEL_EDUCATIONAL_CONDITIONS` — Nobel Prize Outreach; show exact credit, copyright notice, and nobelprize.org citation. File must not be modified.
- `NOBEL_ILLUSTRATION_NONCOMMERCIAL` — Johan Jarnestad / Royal Swedish Academy; non-commercial educational use only; show exact credit.
- `PERMISSION_REQUIRED` — rights unknown or restricted; do not display without written confirmation.
- `UNKNOWN_VERIFY` — source not yet confirmed; keep out of main presentation.
